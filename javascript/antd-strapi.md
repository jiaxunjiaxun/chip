# Strapi and Ant-design Pro

## 安装

```bash
# path: /project
# Create an environment directory for the project
mkdir env

# path: /project/env
# Do not use golobal environment
# Use simple template
cd env
npm i @ant-design/pro-cli
cd node_modules/@ant-design/pro-cli
npx pro create /project/my-antd

# path: /project/my-antd
#
cd /project/my-antd
npm i
npm run start


```
